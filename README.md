# PRISMO — Configurateur Ultra Chrome

Site web interactif pour la marque de couture **PRISMO**, réalisé dans le cadre d'une SAE.

## Présentation

PRISMO est une marque de vêtements haut de gamme dont l'univers est basé sur la lumière, les matières brillantes et les couleurs intenses. Ce site permet aux clients de visualiser et personnaliser un bustier en temps réel avant de le commander.

## Pages

- `accueil.html` — Page d'accueil de présentation de la marque
- `index.html` — Configurateur de produit interactif

## Fonctionnalités

- **Choix de la couleur** : palette de couleurs presets + sélecteur libre, appliqués en temps réel sur le vêtement avec un effet glitch
- **Choix de la matière** : Sequin, Mosaïque, Diamant ou Sans matière, avec effet glitch au changement
- **Prix dynamique** : le prix se met à jour automatiquement selon la matière choisie
- **Bouton Ajouter au panier** : retour visuel au clic
- **Page d'accueil** : présentation de l'univers de la marque avec navigation vers le configurateur

## Technologies utilisées

- HTML / CSS / JavaScript (vanilla, sans framework)
- SVG pour la superposition des matières sur le vêtement
- jscolor pour le sélecteur de couleur personnalisé
- Google Fonts (Space Grotesk, Space Mono)
- Hébergement via GitHub Pages

## Lancer le projet

Ouvrir `accueil.html` dans un navigateur, ou accéder directement à `index.html` pour le configurateur.
